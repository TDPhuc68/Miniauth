OAuth 2.0 / OIDC Public Client

Demo Client Web Application

Đây là ứng dụng Web Client mẫu (Single Page App) minh họa cách tích hợp chuẩn xác luồng Authorization Code Grant với PKCE (RFC 7636) vào hệ thống MiniAuth IAM Server.

  • 🛡️ PKCE S256: Tự động sinh chuỗi code_verifier và băm SHA-256 trên trình duyệt.
  • 🔄 Single Sign-On: Chuyển hướng sang MiniAuth để đăng nhập và xin quyền.
  • 🔑 JWT RS256: Nhận Access Token và ID Token chuẩn RFC 7519.
Client ID: demo-client | Callback: http://localhost:3000/callback.html
